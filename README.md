## Возможности

- **Поиск вакансий** по ключевым словам, городу и графику работы
- **Фильтр "Только в названии"** — мгновенная фильтрация результатов в реальном времени
- **Визуальная статистика**:
  - Топ навыков и технологий
  - Распределение по опыту работы и графику
  - Диаграмма зарплат (минимум, медиана, максимум)
  - Частые тандемы технологий
- **Экспорт в CSV** — скачивание результатов поиска
- **Ленивая загрузка описаний** — описание загружается по клику "Подробнее"
- **Пагинация** — по 15 вакансий за раз с кнопкой "Загрузить ещё"

## Установка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/your-username/HHAnalyzer.git
cd HHAnalyzer
```

### 2. Создайте виртуальное окружение

```bash
python -m venv venv
source venv/bin/activate  # macOS/Linux
# venv\Scripts\activate   # Windows
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

## Использование

### Поиск вакансий

1. Введите поисковый запрос (например: `Python разработчик`)
2. При необходимости выберите город и график работы
3. Нажмите **"Найти"**
4. Дождитесь результатов (загрузка может занять до 2 минут)

### Фильтр "Только в названии"

- Включите чекбокс **"Только в названии"** рядом с кнопкой CSV
- Список вакансий и статистика мгновенно обновятся
- При включённом фильтре CSV скачается только с отфильтрованными вакансиями

### Просмотр описания

- Нажмите **"Подробнее"** на любой вакансии
- Описание загрузится в модальном окне

### Экспорт в CSV

- Нажмите кнопку **"CSV"** для скачивания файла
- Файл будет назван поисковым запросом (например: `python_разработчик.csv`)
- При активном фильтре "Только в названии" экспортируются только отфильтрованные вакансии

### Пагинация

- По умолчанию отображается 15 вакансий
- Нажмите **"Загрузить ещё"** внизу списка для загрузки следующих 25
